## Description

`CodeSection` is a React component for displaying and editing code with a modern interface based on Monaco Editor.

 It provides buttons to copy the code, download it, and customize the appearance.

## Props

| Prop              | Type      | Default         | Description                                              |
|-------------------|-----------|-----------------|----------------------------------------------------------|
| `height`          | `string`  | "90vh"          | Height of the editor                                     |
| `defaultLanguage` | `string`  | "javascript"    | Code language (for syntax highlighting)                  |
| `defaultValue`    | `string`  | "// some comment" | Default displayed code                                 |
| `className`       | `string`  | ""              | Additional CSS classes                                   |
| `isEditable`      | `boolean` | `true`           | Allows code editing                                      |
| `variant`         | `"default" \| "outline" \| "ghost"` | "default" | Visual style of the container                            |

## Usage Example

```tsx
<CodeSection
  height="400px"
  defaultLanguage="python"
  defaultValue={`def hello():\n    print('Hello, World!')`}
  variant="outline"
/>
```
