# AI Searchbar

Un composant de barre de recherche intelligente avec des animations fluides et des interactions avancées.

## Utilisation

```tsx
import { AiSearchbar } from '@/components/LY UI/AI/ai-searchbar'

export default function SearchExample() {
  return (
    <AiSearchbar
      placeholder="Rechercher..."
      onSearch={(query) => console.log(query)}
    />
  )
}
```

## Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `placeholder` | `string` | `"Rechercher..."` | Texte d'aide dans la barre de recherche |
| `onSearch` | `(query: string) => void` | - | Fonction appelée lors de la recherche |
| `className` | `string` | - | Classes CSS supplémentaires |
| `disabled` | `boolean` | `false` | Désactive la barre de recherche |

## Fonctionnalités

- **Animation fluide** : Transitions douces lors de la saisie
- **Interaction intelligente** : Réponse visuelle aux actions utilisateur
- **Accessibilité** : Support complet des lecteurs d'écran
- **Responsive** : S'adapte à toutes les tailles d'écran

## Exemples

### Recherche avec callback

```tsx
<AiSearchbar
  placeholder="Rechercher des produits..."
  onSearch={(query) => {
    // Logique de recherche
    searchProducts(query)
  }}
/>
```

### Barre de recherche désactivée

```tsx
<AiSearchbar
  placeholder="Recherche temporairement indisponible"
  disabled={true}
/>
```
