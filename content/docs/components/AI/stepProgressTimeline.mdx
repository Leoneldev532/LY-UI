## Props

| Prop                  | Type                                   | Default     | Description                                                        |
|-----------------------|----------------------------------------|-------------|--------------------------------------------------------------------|
| `steps`               | `StepProps[]`                          | `[...]`     | Array of steps to display in the timeline                          |
| `onGenerationStart`   | `() => void`                           | `undefined` | Callback when generation starts                                    |
| `onGenerationComplete`| `() => void`                           | `undefined` | Callback when generation is complete                               |
| `onGenerationStop`    | `() => void`                           | `undefined` | Callback when generation stops                                     |
| `externalStop`        | `boolean`                              | `false`     | External control to stop generation                                |
| `externalStart`       | `boolean`                              | `false`     | External control to start generation                               |
| `className`           | `string`                               | `undefined` | Additional CSS classes for styling                                 |
| `scrollSpeed`         | `"fast" \| "normal" \| "slow"`         | `"normal"`  | Speed of the scroll animation                                      |

### StepProps

| Prop         | Type                                         | Default     | Description                                                        |
|--------------|----------------------------------------------|-------------|--------------------------------------------------------------------|
| `step`       | `number`                                     | `undefined` | Step number                                                        |
| `stepName`   | `string`                                     | `undefined` | Step name to display                                               |
| `duration`   | `number`                                     | `undefined` | Duration in milliseconds for the step                              |
| `status`     | `"waiting..." \| "generating..." \| "completed"`| `"waiting..."`| Current status of the step                                         |

### Example Usage

```jsx
<StepProgressTimeline
  steps={[
    { step: 1, stepName: "Analysis", duration: 2000, status: "waiting..." },
    { step: 2, stepName: "Research", duration: 2500, status: "waiting..." },
    { step: 3, stepName: "Generation", duration: 3000, status: "waiting..." },
    { step: 4, stepName: "Validation", duration: 2000, status: "waiting..." },
  ]}
  externalStart={true}
  className="w-full"
  scrollSpeed="fast"
/>
```
