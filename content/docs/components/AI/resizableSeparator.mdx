# Resizable Separator

Un composant de séparateur redimensionnable permettant de diviser l'espace entre deux panneaux avec une interface intuitive.

## Utilisation

```tsx
import { ResizableSeparator } from '@/components/LY UI/AI/resizableSeparator'

export default function SeparatorExample() {
  return (
    <div className="flex h-96">
      <div className="flex-1 bg-gray-100 p-4">
        Panneau gauche
      </div>
      <ResizableSeparator
        onResize={(newWidth) => {
          console.log('Nouvelle largeur:', newWidth)
        }}
      />
      <div className="flex-1 bg-gray-200 p-4">
        Panneau droit
      </div>
    </div>
  )
}
```

## Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `onResize` | `(width: number) => void` | - | Callback lors du redimensionnement |
| `className` | `string` | - | Classes CSS supplémentaires |
| `minWidth` | `number` | `100` | Largeur minimale en pixels |
| `maxWidth` | `number` | - | Largeur maximale en pixels |
| `defaultWidth` | `number` | `50` | Largeur par défaut en pourcentage |
| `direction` | `"horizontal" \| "vertical"` | `"horizontal"` | Direction du redimensionnement |

## Fonctionnalités

- **Redimensionnement fluide** : Glisser-déposer intuitif
- **Contraintes** : Largeurs minimale et maximale configurables
- **Orientations** : Support horizontal et vertical
- **Accessibilité** : Support complet des lecteurs d'écran
- **Responsive** : S'adapte aux différentes tailles d'écran

## Exemples

### Séparateur horizontal simple

```tsx
<div className="flex h-64">
  <div className="bg-blue-100 p-4">
    Contenu gauche
  </div>
  <ResizableSeparator
    onResize={(width) => setLeftPanelWidth(width)}
    minWidth={150}
    maxWidth={400}
  />
  <div className="bg-green-100 p-4">
    Contenu droit
  </div>
</div>
```

### Séparateur vertical

```tsx
<div className="flex h-96">
  <div className="bg-gray-100 p-4">
    Panneau supérieur
  </div>
  <ResizableSeparator
    direction="vertical"
    onResize={(height) => setTopPanelHeight(height)}
    minWidth={100}
    maxWidth={300}
  />
  <div className="bg-gray-200 p-4">
    Panneau inférieur
  </div>
</div>
```

### Avec contraintes personnalisées

```tsx
<ResizableSeparator
  onResize={(width) => {
    // Mise à jour de l'état
    setPanelWidth(width)
    // Sauvegarde dans localStorage
    localStorage.setItem('panelWidth', width.toString())
  }}
  minWidth={200}
  maxWidth={800}
  defaultWidth={30}
  className="bg-gray-300 hover:bg-gray-400"
/>
```

### Gestion d'état

```tsx
const [leftWidth, setLeftWidth] = useState(300)

<div className="flex h-80">
  <div 
    className="bg-blue-50 p-4"
    style={{ width: `${leftWidth}px` }}
  >
    Panneau avec largeur fixe
  </div>
  <ResizableSeparator
    onResize={setLeftWidth}
    minWidth={150}
    maxWidth={600}
  />
  <div className="flex-1 bg-green-50 p-4">
    Panneau flexible
  </div>
</div>
```
