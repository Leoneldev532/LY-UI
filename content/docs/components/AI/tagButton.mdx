# Tag Button

Un composant de bouton tag permettant la sélection multiple avec gestion d'état et animations fluides.

## Utilisation

```tsx
import { TagButton } from '@/components/LY UI/AI/tagButton'

export default function TagExample() {
  return (
<TagButton
      label="React"
      isSelected={false}
      onToggle={(selected) => {
        console.log('Tag sélectionné:', selected)
      }}
/>
  )
}
```

## Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `label` | `string` | - | Texte du tag |
| `isSelected` | `boolean` | `false` | État de sélection du tag |
| `onToggle` | `(selected: boolean) => void` | - | Callback lors du changement d'état |
| `className` | `string` | - | Classes CSS supplémentaires |
| `disabled` | `boolean` | `false` | Désactive le tag |
| `variant` | `"default" \| "outline" \| "ghost"` | `"default"` | Variante visuelle |
| `size` | `"sm" \| "md" \| "lg"` | `"md"` | Taille du tag |

## Variantes

- **default** : Style par défaut avec fond coloré
- **outline** : Contour avec fond transparent
- **ghost** : Style minimal sans bordure

## Exemples

### Tag simple

```tsx
<TagButton
  label="JavaScript"
  isSelected={true}
  onToggle={(selected) => {
    setSelectedTags(prev => 
      selected 
        ? [...prev, "JavaScript"]
        : prev.filter(tag => tag !== "JavaScript")
    )
  }}
/>
```

### Groupe de tags

```tsx
const [selectedTags, setSelectedTags] = useState<string[]>([])

const tags = ["React", "Vue", "Angular", "Svelte"]

<div className="flex flex-wrap gap-2">
  {tags.map(tag => (
    <TagButton
      key={tag}
      label={tag}
      isSelected={selectedTags.includes(tag)}
      onToggle={(selected) => {
        if (selected) {
          setSelectedTags(prev => [...prev, tag])
        } else {
          setSelectedTags(prev => prev.filter(t => t !== tag))
        }
      }}
    />
  ))}
</div>
```

### Tags avec variantes

```tsx
<TagButton
  label="Premium"
  variant="outline"
  size="lg"
  isSelected={true}
  onToggle={(selected) => {
    setPremiumSelected(selected)
  }}
  className="border-2 border-gold-500 text-gold-700"
/>
```

### Tags désactivés

```tsx
<TagButton
  label="Indisponible"
  isSelected={false}
  disabled={true}
  variant="ghost"
  className="opacity-50 cursor-not-allowed"
/>
```
