## Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `icon` | `ReactNode` | - | Icon component to display |
| `title` | `string` | - | Text content for the button |
| `variant` | `"default" \| "outline" \| "ghost"` | `"default"` | Visual style variant |
| `onClick` | `() => void` | - | Click handler function |
| `className` | `string` | - | Additional CSS classes |

## forwardRef and ref management

The TagButton component uses `forwardRef` to pass references to the underlying button element. 
This allows you to access the button directly for imperative operations like focusing or programmatic clicks.
