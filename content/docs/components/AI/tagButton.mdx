## Props

| Prop         | Type                                   | Default     | Description                                 |
|--------------|----------------------------------------|-------------|---------------------------------------------|
| `icon`       | `ReactNode`                            | -           | Icon component to display                   |
| `title`      | `string`                               | -           | Text content for the button                 |
| `variant`    | `"default" \| "outline" \| "ghost"` | `"default"` | Visual style variant                        |
| `onClick`    | `() => void`                           | -           | Click handler function                      |
| `items`      | `string[]`                             | `[]`        | List of items for dropdown selection        |
| `onItemClick`| `(item: string) => void`               | -           | Callback when a dropdown item is selected   |
| `className`  | `string`                               | -           | Additional CSS classes                      |

## Dropdown & Focus Behavior

- **Dropdown**: If `items` is provided, clicking the button opens a dropdown menu. Only one TagButton dropdown can be open at a time (global management).
- **Animation**: Dropdown uses motion for smooth appearance/disappearance.
- **Focus**: The component supports programmatic focus via ref (forwardRef).
- **Keyboard Accessibility**: Fully keyboard accessible for all controls.

## forwardRef and ref management

The TagButton component uses `forwardRef` to pass references to the underlying button element. This allows you to access the button directly for imperative operations like focusing or programmatic clicks.
