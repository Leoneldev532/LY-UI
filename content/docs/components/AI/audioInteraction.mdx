## Example

```tsx
import { AudioInteraction } from '@/components/LY UI/AI/audioInteraction'

export default function AudioExample() {
  const handleAudioStart = () => {
    console.log('Audio recording started')
    // Logic to start recording
  }

  const handleAudioStop = () => {
    console.log('Audio recording stopped')
    // Logic to stop recording
  }

  const handleAudioPause = () => {
    console.log('Audio recording paused')
    // Logic to pause
  }

  const handleAudioResume = () => {
    console.log('Audio recording resumed')
    // Logic to resume recording
  }

  return (
    <div className="space-y-4">
      <AudioInteraction
        onAudioStart={handleAudioStart}
        onAudioStop={handleAudioStop}
        onAudioPause={handleAudioPause}
        onAudioResume={handleAudioResume}
        className="w-full max-w-md"
      />
    </div>
  )
}
```

## Documentation

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `onAudioStart` | `() => void` | - | Callback called when audio starts |
| `onAudioStop` | `() => void` | - | Callback called when audio stops |
| `onAudioPause` | `() => void` | - | Callback called when audio is paused |
| `onAudioResume` | `() => void` | - | Callback called when audio resumes |
| `className` | `string` | - | Additional CSS classes |

## States

- **idle** : Initial state, ready to start
- **playing** : Currently playing/recording
- **paused** : Paused

## Features

- **Particle animations** : Visual effect during audio interaction
- **Playback controls** : Start, Pause, Resume, Stop buttons
- **Integrated timer** : Display of elapsed time in MM:SS format
- **Complete callbacks** : Notifications for all audio events
- **Visual states** : Interface that adapts to current state
- **Responsive** : Adapts to all screen sizes
- **Accessibility** : Screen reader support
