# Audio Interaction

Un composant d'interaction audio permettant l'enregistrement de voix et la reconnaissance vocale avec des animations visuelles.

## Utilisation

```tsx
import { AudioInteraction } from '@/components/LY UI/AI/audioInteraction'

export default function AudioExample() {
  return (
    <AudioInteraction
      onRecordingComplete={(audioBlob) => {
        console.log('Audio enregistré:', audioBlob)
      }}
      onTranscription={(text) => {
        console.log('Transcription:', text)
      }}
    />
  )
}
```

## Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `onRecordingComplete` | `(audioBlob: Blob) => void` | - | Callback appelé quand l'enregistrement est terminé |
| `onTranscription` | `(text: string) => void` | - | Callback appelé avec la transcription du texte |
| `className` | `string` | - | Classes CSS supplémentaires |
| `isRecording` | `boolean` | `false` | Contrôle externe de l'état d'enregistrement |
| `autoTranscribe` | `boolean` | `true` | Transcription automatique après enregistrement |
| `maxDuration` | `number` | `30000` | Durée maximale d'enregistrement en ms |

## États

- **idle** : Prêt à enregistrer
- **recording** : En cours d'enregistrement
- **processing** : Traitement de l'audio
- **transcribing** : Transcription en cours

## Fonctionnalités

- **Enregistrement audio** : Capture audio via le microphone
- **Visualisation** : Animations visuelles pendant l'enregistrement
- **Transcription** : Reconnaissance vocale automatique
- **Contrôle de durée** : Limite la durée d'enregistrement
- **Accessibilité** : Support complet des lecteurs d'écran

## Exemples

### Enregistrement simple

```tsx
<AudioInteraction
  onRecordingComplete={(blob) => {
    // Sauvegarder l'audio
    const url = URL.createObjectURL(blob)
    const a = document.createElement('a')
    a.href = url
    a.download = 'enregistrement.wav'
    a.click()
  }}
/>
```

### Avec transcription personnalisée

```tsx
<AudioInteraction
  onTranscription={(text) => {
    // Traitement personnalisé de la transcription
    setTranscribedText(text)
    sendToAI(text)
  }}
  autoTranscribe={true}
  maxDuration={60000} // 1 minute
/>
```

### Contrôle externe

```tsx
const [isRecording, setIsRecording] = useState(false)

<AudioInteraction
  isRecording={isRecording}
  onRecordingComplete={(blob) => {
    setIsRecording(false)
    handleAudioComplete(blob)
  }}
/>
```
