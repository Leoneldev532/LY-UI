## Props

| Prop                  | Type                              | Default     | Description                                                        |
|-----------------------|-----------------------------------|-------------|--------------------------------------------------------------------|
| `content`             | `string[]`                        | `[]`        | Array of text content to display in the animation                  |
| `className`           | `string`                          | `undefined` | Additional CSS classes for styling                                 |
| `scrollDirection`     | `"up" \| "down"`                  | `"up"`      | Direction of the scrolling animation                               |
| `animationSpeed`      | `"slow" \| "normal" \| "fast"`     | `"normal"`  | Speed of the animation                                             |
| `variant`             | `"default" \| "ghost" \| "outline"`| `"default"` | Visual style variant of the component                              |
| `step`                | `number`                          | `undefined` | Optional step index for advanced control                           |
| `callBackAnimationEnd`| `() => void`                      | `undefined` | Callback called when the animation ends                            |

### Example Usage

```jsx
import ThinkingSearchAnimation from "@/components/LY UI/AI/thinkingSearchAnimation";

<ThinkingSearchAnimation
  content={[
    "Analyzing your question...",
    "Searching for relevant information...",
    "Compiling the best answer...",
    "Almost ready..."
  ]}
  scrollDirection="up"
  animationSpeed="normal"
  className="max-w-md"
  variant="default"
  step={1}
  callBackAnimationEnd={() => console.log('Animation ended')}
/>
```
