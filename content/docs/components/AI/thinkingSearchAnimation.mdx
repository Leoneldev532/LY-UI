## Example

```tsx
export default function ThinkingSearchAnimationExample() {
  const streamingText = "Searching through databases... Analyzing patterns... Processing information... Generating insights... Finalizing results..."

  const messages = [
    { role: "user", content: "How can I improve my React performance?" },
    { role: "assistant", content: "Let me search for the best practices..." },
    { role: "assistant", content: "Found several optimization techniques..." },
    { role: "assistant", content: "Here are the key strategies..." },
  ]

  const handleAnimationComplete = () => {
    console.log('Thinking animation completed')
  }

  return (
    <ThinkingSearchAnimation
      streamingText={streamingText}
      messages={messages}
      animationSpeed="normal"
      scrollDirection="up"
      variant="ghost"
      onAnimationComplete={handleAnimationComplete}
      className="w-full"
    />
  )
}
```

## Documentation

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `streamingText` | `string` | `""` | Text to display in streaming animation |
| `messages` | `{ role: string; content: string }[]` | `[]` | Array of conversation messages |
| `animationSpeed` | `"slow" \| "normal" \| "fast"` | `"normal"` | Speed of the animation |
| `scrollDirection` | `"up" \| "down"` | `"up"` | Direction of text scrolling |
| `variant` | `"streamingText" \| "messages"` | `"streamingText"` | Display variant |
| `onAnimationComplete` | `() => void` | `undefined` | Callback when animation completes |
| `className` | `string` | `undefined` | Additional CSS classes for styling |

### Types

```tsx
type ThinkingSearchAnimationProps = {
  streamingText?: string
  messages?: { role: string; content: string }[]
  animationSpeed?: "slow" | "normal" | "fast"
  scrollDirection?: "up" | "down"
  variant?: "streamingText" | "messages"
  onAnimationComplete?: () => void
  className?: string
}
```

## Features

- **Streaming Text Animation**: Progressive text reveal with customizable speed
- **Message Display**: Support for conversation-style message display
- **Customizable Speed**: Three animation speed options (slow, normal, fast)
- **Scroll Direction**: Configurable upward or downward scrolling
- **Multiple Variants**: Streaming text and messages display modes
- **Responsive Design**: Adapts to different screen sizes with proper text wrapping
- **Dark Mode Support**: Full dark mode compatibility with appropriate styling
- **Accessibility Focused**: Screen reader friendly with proper semantic structure
