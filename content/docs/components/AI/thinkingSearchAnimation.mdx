## Example

```tsx
import { ThinkingSearchAnimation } from '@/components/LY UI/AI/thinkingSearchAnimation'

export default function SearchExample() {
  const streamingText = `
    Analyzing user data...
    
    Searching for patterns in previous interactions.
    Identifying preferences and behaviors.
    
    Generating personalized recommendations.
    Optimizing results to maximize engagement.
    
    Finalizing and validating suggestions.
  `

  const messages = [
    "First step of analysis...",
    "Processing user data...",
    "Generating recommendations...",
    "Optimizing results..."
  ]

  const handleAnimationEnd = () => {
    console.log('Search animation ended')
  }

  return (
    <div className="space-y-4">
      {/* With streamingText */}
      <ThinkingSearchAnimation
        variant="default"
        streamingText={streamingText}
        scrollDirection="up"
        animationSpeed="normal"
        onAnimationEnd={handleAnimationEnd}
        minParagraphLength={50}
        className="w-full max-w-2xl"
      />

      {/* With messages */}
      <ThinkingSearchAnimation
        variant="outline"
        messages={messages}
        scrollDirection="down"
        animationSpeed="fast"
        onAnimationEnd={handleAnimationEnd}
      />
    </div>
  )
}
```

## Documentation

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `variant` | `"default" \| "ghost" \| "outline"` | `"default"` | Visual style of the component |
| `streamingText` | `string` | - | Text to automatically process into paragraphs |
| `messages` | `string[]` | - | Array of messages to display directly |
| `onAnimationEnd` | `() => void` | - | Callback called when animation ends |
| `className` | `string` | - | Additional CSS classes |
| `scrollDirection` | `"up" \| "down"` | `"up"` | Scroll direction |
| `animationSpeed` | `"slow" \| "normal" \| "fast"` | `"normal"` | Animation speed |
| `minParagraphLength` | `number` | `50` | Minimum length for auto-generated paragraphs |
| `sentenceEndPattern` | `RegExp` | `/[.!?]\s+/g` | Pattern to split sentences |

## Features

- **Automatic processing** : Intelligent text division into paragraphs
- **Smooth animations** : Automatic scrolling with smooth transitions
- **Visual variants** : Three different styles (default, ghost, outline)
- **Animation controls** : Configurable speed and direction
- **Loading state** : Display while waiting for content
- **Collapsible** : Ability to collapse/expand content
- **Responsive** : Adapts to all screen sizes
- **Accessibility** : Screen reader support
