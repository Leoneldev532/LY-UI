## Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `question` | `string` | `undefined` | The question text to display and edit |
| `className` | `string` | `undefined` | Additional CSS classes for styling |
| `onQuestionChange` | `(value: string) => void` | `undefined` | Callback when the question text changes |

## forwardRef and ref management

The EditableQuestion component uses forwardRef to pass references to the underlying div element. This allows you to access the question container directly for imperative operations like focusing or measuring.

```tsx
import { useRef } from 'react';
import EditableQuestion from "@/components/LY UI/AI/editableQuestion";

const MyComponent = () => {
  const questionRef = useRef<HTMLDivElement>(null);

  const focusQuestion = () => {
    if (questionRef.current) {
      const textarea = questionRef.current.querySelector('textarea');
      if (textarea) {
        textarea.focus();
      }
    }
  };

  const getQuestionHeight = () => {
    if (questionRef.current) {
      return questionRef.current.offsetHeight;
    }
    return 0;
  };

  return (
    <EditableQuestion
      ref={questionRef}
      question="What is the impact of AI on drug sales?"
      className="w-full"
      onQuestionChange={(value) => console.log("Question changed:", value)}
    />
  );
};
```
