## Props

| Prop               | Type                | Default     | Description                                              |
|--------------------|---------------------|-------------|----------------------------------------------------------|
| `className`        | `string`            | `undefined` | Additional CSS classes for styling                       |
| `question`         | `string`            | `""`        | The question text to display and edit                    |
| `onQuestionChange` | `(string) => void`  | `undefined` | Callback when the question text changes                  |

## Interactive Behaviors

- **Copy Button**: Copies the question to clipboard. Shows a check icon as feedback when copied.
- **Inline Editing**: Click the edit icon to edit. Validate with Ctrl+Enter, cancel with Escape.
- **Keyboard Accessibility**: Fully keyboard accessible (tab, enter, escape, etc).
- **Focus**: Supports programmatic focus via ref (forwardRef).

## forwardRef and ref management

The EditableQuestion component uses forwardRef to pass references to the underlying div element. This allows you to access the question container directly for imperative operations like focusing or measuring.

### Example Usage

```jsx
import EditableQuestion from "@/components/LY UI/AI/editableQuestion";

<EditableQuestion
  question="What is the impact of AI on drug sales?"
  className="w-full"
  onQuestionChange={(value) => console.log("Question changed:", value)}
/>
```
