# Editable Question

Un composant de question éditable permettant aux utilisateurs de modifier et valider leurs questions avec une interface intuitive.

## Utilisation

```tsx
import { EditableQuestion } from '@/components/LY UI/AI/editableQuestion'

export default function QuestionExample() {
  return (
    <EditableQuestion
      initialQuestion="Comment créer un composant React ?"
      onQuestionChange={(newQuestion) => {
        console.log('Question modifiée:', newQuestion)
      }}
      onQuestionSubmit={(finalQuestion) => {
        console.log('Question soumise:', finalQuestion)
      }}
    />
  )
}
```

## Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `initialQuestion` | `string` | `""` | Question initiale à afficher |
| `onQuestionChange` | `(question: string) => void` | - | Callback lors de la modification |
| `onQuestionSubmit` | `(question: string) => void` | - | Callback lors de la soumission |
| `className` | `string` | - | Classes CSS supplémentaires |
| `placeholder` | `string` | `"Posez votre question..."` | Texte d'aide |
| `maxLength` | `number` | `500` | Longueur maximale de la question |
| `isEditing` | `boolean` | `false` | Contrôle externe du mode édition |

## États

- **view** : Affichage en lecture seule
- **editing** : Mode édition actif
- **validating** : Validation en cours
- **submitting** : Soumission en cours

## Fonctionnalités

- **Édition inline** : Modification directe du texte
- **Validation** : Vérification de la longueur et du contenu
- **Auto-sauvegarde** : Sauvegarde automatique des modifications
- **Historique** : Possibilité d'annuler les modifications
- **Accessibilité** : Support complet des lecteurs d'écran

## Exemples

### Question simple

```tsx
<EditableQuestion
  initialQuestion="Qu'est-ce que React ?"
  onQuestionSubmit={(question) => {
    // Envoyer la question à l'IA
    sendToAI(question)
  }}
/>
```

### Avec validation personnalisée

```tsx
<EditableQuestion
  initialQuestion=""
  placeholder="Décrivez votre problème..."
  maxLength={1000}
  onQuestionChange={(question) => {
    // Validation personnalisée
    if (question.length < 10) {
      setError("La question doit contenir au moins 10 caractères")
    } else {
      setError(null)
    }
  }}
/>
```

### Contrôle externe

```tsx
const [isEditing, setIsEditing] = useState(false)

<EditableQuestion
  initialQuestion="Question par défaut"
  isEditing={isEditing}
  onQuestionSubmit={(question) => {
    setIsEditing(false)
    handleQuestionSubmit(question)
  }}
/>
```
