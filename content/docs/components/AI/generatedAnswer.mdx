## Example

```tsx
import { GeneratedAnswer } from '@/components/LY UI/AI/generatedAnswer'

export default function AnswerExample() {
  const content = `
# Answer Title

Here is a **generated answer** by AI with markdown formatting.

## Features

- Progressive text animation
- Markdown support
- Interactive controls
- Customizable timestamp

\`\`\`javascript
console.log("Code example")
\`\`\`
  `

  const handleAnimationEnd = () => {
    console.log('Animation ended')
  }

  const handleComplete = () => {
    console.log('Answer completed')
  }

  return (
    <GeneratedAnswer
      content={content}
      timestamp="14:32"
      isLoading={false}
      onEndAnimation={handleAnimationEnd}
      onComplete={handleComplete}
      textSpeed={30}
      markdownMode={true}
      hideControls={false}
      className="w-full max-w-2xl"
    />
  )
}
```

## Documentation

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `content` | `string` | `""` | Answer content to display |
| `timestamp` | `string` | `"00:00"` | Timestamp displayed in controls |
| `isLoading` | `boolean` | `false` | If true, shows loader instead of content |
| `LoaderComponent` | `React.ReactNode` | - | Custom loading component |
| `onEndAnimation` | `() => void` | - | Callback called when animation ends |
| `onComplete` | `() => void` | - | Callback called when answer is complete |
| `textSpeed` | `number` | `30` | Text animation speed (ms between each character) |
| `markdownMode` | `boolean` | `false` | Enables markdown rendering of content |
| `hideControls` | `boolean` | `false` | Hides the control bar |
| `className` | `string` | - | Additional CSS classes |

## Features

- **Progressive animation** : Character-by-character display with configurable speed
- **Markdown support** : Complete markdown formatting rendering
- **Interactive controls** : Copy, like, dislike, regenerate buttons
- **Loading states** : Support for custom loaders
- **Callbacks** : Notifications for animation events
- **Responsive** : Adapts to all screen sizes
- **Accessibility** : Screen reader support
