# Generated Answer

Un composant d'affichage de réponses générées par IA avec formatage automatique, animations de progression et support du markdown.

## Utilisation

```tsx
import { GeneratedAnswer } from '@/components/LY UI/AI/generatedAnswer'

export default function AnswerExample() {
  return (
    <GeneratedAnswer
      content="Voici votre réponse générée par l'IA..."
      isGenerating={false}
      onCopy={(text) => {
        console.log('Réponse copiée:', text)
      }}
    />
  )
}
```

## Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `content` | `string` | `""` | Contenu de la réponse à afficher |
| `isGenerating` | `boolean` | `false` | Indique si la réponse est en cours de génération |
| `onCopy` | `(text: string) => void` | - | Callback lors de la copie |
| `className` | `string` | - | Classes CSS supplémentaires |
| `showCopyButton` | `boolean` | `true` | Affiche le bouton de copie |
| `autoScroll` | `boolean` | `true` | Défilement automatique pendant la génération |
| `markdown` | `boolean` | `true` | Active le formatage markdown |

## Fonctionnalités

- **Formatage markdown** : Support complet du markdown avec syntax highlighting
- **Animation de progression** : Affichage progressif du texte
- **Copie facile** : Bouton de copie avec feedback visuel
- **Défilement automatique** : Suit automatiquement le contenu en cours de génération
- **Responsive** : S'adapte à toutes les tailles d'écran

## Exemples

### Réponse simple

```tsx
<GeneratedAnswer
  content="React est une bibliothèque JavaScript pour créer des interfaces utilisateur."
  isGenerating={false}
/>
```

### Réponse en cours de génération

```tsx
<GeneratedAnswer
  content="Voici les étapes pour créer un composant React..."
  isGenerating={true}
  onCopy={(text) => {
    navigator.clipboard.writeText(text)
    toast.success('Réponse copiée !')
  }}
/>
```

### Avec markdown personnalisé

```tsx
<GeneratedAnswer
  content={`
# Titre principal

Voici une **réponse** avec du *formatage* markdown.

\`\`\`javascript
const component = () => {
  return <div>Hello World</div>
}
\`\`\`
  `}
  isGenerating={false}
  markdown={true}
  showCopyButton={true}
/>
```

### Sans bouton de copie

```tsx
<GeneratedAnswer
  content="Réponse sans possibilité de copie"
  isGenerating={false}
  showCopyButton={false}
  className="border rounded-lg p-4"
/>
```
