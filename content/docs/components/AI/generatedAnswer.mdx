## Props

| Prop             | Type                | Default     | Description                                              |
|------------------|---------------------|-------------|----------------------------------------------------------|
| `content`        | `string`            | `""`        | The content of the AI-generated answer                   |
| `className`      | `string`            | `undefined` | Additional CSS classes for styling                       |
| `timestamp`      | `string`            | `"00:00"`   | Time displayed at the bottom of the answer               |
| `isLoading`      | `boolean`           | `false`     | Whether the answer is loading                            |
| `LoaderComponent`| `React.ReactNode`   | `undefined` | Custom loader component to display while loading         |
| `onEndAnimation` | `() => void`        | `undefined` | Callback when the answer animation ends                  |
| `onComplete`     | `() => void`        | `undefined` | Callback when the answer is fully displayed              |
| `textSpeed`      | `number`            | `30`        | Speed of the text animation (ms per character)           |
| `markdownMode`   | `boolean`           | `false`     | If true, renders the content as markdown                 |
| `hideControls`   | `boolean`           | `false`     | Hide the action buttons (like, dislike, copy, etc.)      |

## forwardRef and ref management

The GeneratedAnswer component uses forwardRef to pass references to the underlying div element. This allows you to access the answer container directly for imperative operations like scrolling or measuring.

```tsx
import { useRef } from 'react';
import GeneratedAnswer from "@/components/LY UI/AI/generatedAnswer";

const MyComponent = () => {
  const answerRef = useRef<HTMLDivElement>(null);

  const scrollToTop = () => {
    if (answerRef.current) {
      answerRef.current.scrollTop = 0;
    }
  };

  const getAnswerHeight = () => {
    if (answerRef.current) {
      return answerRef.current.offsetHeight;
    }
    return 0;
  };

  return (
    <GeneratedAnswer
      ref={answerRef}
      hideControls={true}
      markdownMode={true}
      onComplete={() => console.log('Answer fully displayed!')}
      content="AI is revolutionizing drug sales by optimizing inventory management."
      timestamp="12:34"
      className="w-full"
    />
  );
};
```
