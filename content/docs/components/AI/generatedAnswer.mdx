## Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `content` | `string` | `undefined` | The content of the AI-generated answer |
| `className` | `string` | `undefined` | Additional CSS classes for styling |
| `timestamp` | `string` | `"00:00"` | Time displayed at the bottom of the answer |

## forwardRef and ref management

The GeneratedAnswer component uses forwardRef to pass references to the underlying div element. This allows you to access the answer container directly for imperative operations like scrolling or measuring.

```tsx
import { useRef } from 'react';
import GeneratedAnswer from "@/components/LY UI/AI/generatedAnswer";

const MyComponent = () => {
  const answerRef = useRef<HTMLDivElement>(null);

  const scrollToTop = () => {
    if (answerRef.current) {
      answerRef.current.scrollTop = 0;
    }
  };

  const getAnswerHeight = () => {
    if (answerRef.current) {
      return answerRef.current.offsetHeight;
    }
    return 0;
  };

  return (
    <GeneratedAnswer
      ref={answerRef}
      content="AI is revolutionizing drug sales by optimizing inventory management."
      timestamp="12:34"
      className="w-full"
    />
  );
};
```
