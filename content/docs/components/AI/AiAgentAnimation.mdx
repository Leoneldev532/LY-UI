# AI Agent Animation

Un composant d'animation spécialement conçu pour les agents IA avec des transitions fluides et des états visuels dynamiques.

## Utilisation

```tsx
import { AiAgentAnimation } from '@/components/LY UI/AI/AiAgentAnimation'

export default function AgentExample() {
  return (
    <AiAgentAnimation
      isActive={true}
      status="thinking"
      className="w-16 h-16"
    />
  )
}
```

## Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `isActive` | `boolean` | `false` | Active l'animation de l'agent |
| `status` | `"idle" \| "thinking" \| "speaking" \| "listening"` | `"idle"` | État actuel de l'agent |
| `className` | `string` | - | Classes CSS supplémentaires |
| `size` | `"sm" \| "md" \| "lg"` | `"md"` | Taille de l'animation |

## États de l'agent

- **idle** : Agent en attente, animation minimale
- **thinking** : Agent en train de réfléchir, animation de pulsation
- **speaking** : Agent en train de parler, animation de parole
- **listening** : Agent en train d'écouter, animation d'écoute

## Exemples

### Agent en train de réfléchir

```tsx
<AiAgentAnimation
  isActive={true}
  status="thinking"
  size="lg"
/>
```

### Agent en mode écoute

```tsx
<AiAgentAnimation
  isActive={true}
  status="listening"
  className="w-12 h-12"
/>
```

### Agent inactif

```tsx
<AiAgentAnimation
  isActive={false}
  status="idle"
/>
```
