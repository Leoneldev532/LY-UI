## Example

```tsx
import { AiAgentAnimation } from '@/components/LY UI/AI/AiAgentAnimation'

export default function AgentExample() {
  const handleAnimationComplete = () => {
    console.log('Animation completed')
  }

  const handleAnimationStart = () => {
    console.log('Animation started')
  }

  return (
    <AiAgentAnimation
      title="AI Assistant"
      duration={5000}
      isRunning={true}
      onAnimationComplete={handleAnimationComplete}
      onAnimationStart={handleAnimationStart}
      onAnimationStop={() => console.log('Animation stopped')}
      onAnimationReset={() => console.log('Animation reset')}
      columns={8}
      rows={3}
      pauseDuration={1000}
      dotType="round"
      className="w-full max-w-md"
    />
  )
}
```

## Documentation

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `title` | `string` | `"Agent"` | Title displayed before the percentage |
| `duration` | `number` | `3000` | Animation duration in milliseconds |
| `onAnimationComplete` | `() => void` | - | Callback called at the end of animation |
| `columns` | `number` | - | Number of dot columns (automatically calculated if not specified) |
| `rows` | `number` | `3` | Number of dot rows |
| `className` | `string` | - | Additional CSS classes |
| `pauseDuration` | `number` | `500` | Pause duration between each cycle (ms) |
| `isRunning` | `boolean` | `false` | External control of animation state |
| `onAnimationStart` | `() => void` | - | Callback called when animation starts |
| `onAnimationStop` | `() => void` | - | Callback called when animation stops |
| `onAnimationReset` | `() => void` | - | Callback called when animation is reset |
| `dotType` | `"round" \| "square"` | `"round"` | Shape of the dots |

## Features

- **Smooth animation** : Smooth transitions between states
- **External control** : Ability to control animation from outside
- **Complete callbacks** : Notifications for all animation events
- **Responsive** : Automatic adaptation of column count
- **Customization** : Choice of dot shape and duration
- **Accessibility** : Screen reader support
