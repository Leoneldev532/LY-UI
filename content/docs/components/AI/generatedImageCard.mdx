### Example Usage

```jsx
<GeneratedImageCard
  src="https://via.placeholder.com/150"
  title="AI Generated Image"
  width={400}
  height={400}
  prompt="A blue bird on a branch"
  hours="10:00"
/>
```

## Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `src` | `string \| Blob \| StaticImport` | `"https://via.placeholder.com/150"` | Source of the image to display |
| `title` | `string \| null` | `undefined` | Title of the image |
| `width` | `number` | `2225` | Width of the image |
| `height` | `number` | `2465` | Height of the image |
| `className` | `string` | `undefined` | Additional CSS classes for styling |
| `hours` | `string` | `"00:00"` | Time displayed at the bottom of the card |
| `prompt` | `string` | `""` | The prompt used to generate the image |
| `onLike` | `() => void` | `undefined` | Callback when user likes the image |
| `onDislike` | `() => void` | `undefined` | Callback when user dislikes the image |
| `onRegenerate` | `() => void` | `undefined` | Callback when user requests regeneration |
