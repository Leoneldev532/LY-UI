## Example

```tsx
import { GeneratedImageCard } from '@/components/LY UI/AI/generatedImageCard'

export default function ImageExample() {
  const handleLike = () => {
    console.log('User liked the image')
    // Logic to save the like
  }

  const handleDislike = () => {
    console.log('User disliked the image')
    // Logic to save the dislike
  }

  const handleRegenerate = () => {
    console.log('Image regeneration requested')
    // Logic to regenerate the image
  }

  return (
    <div className="space-y-4">
      {/* With image URL */}
      <GeneratedImageCard
        src="https://example.com/generated-image.jpg"
        imageTitle="Mountain Landscape"
        prompt="A mountain landscape at sunset, realistic style"
        timestamp="14:32"
        onLike={handleLike}
        onDislike={handleDislike}
        onRegenerate={handleRegenerate}
        onComplete={() => console.log('Image loaded successfully')}
        width={400}
        height={400}
        className="w-full max-w-md"
      />

      {/* With Blob (after generation) */}

        src={imageBlob}
```

## Documentation

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `src` | `string \| Blob \| StaticImport` | - | Image source (URL, Blob, or static import) |
| `imageTitle` | `string \| null` | - | Image title |
| `width` | `number` | `400` | Image width |
| `height` | `number` | `400` | Image height |
| `timestamp` | `string` | `"00:00"` | Displayed timestamp |
| `prompt` | `string` | `""` | Prompt used to generate the image |
| `onLike` | `() => void` | - | Callback called on like |
| `onDislike` | `() => void` | - | Callback called on dislike |
| `onRegenerate` | `() => void` | - | Callback called on regeneration |
| `onComplete` | `() => void` | - | Callback called when image is loaded |
| `hideControls` | `boolean` | `false` | Hides interactive controls |
| `className` | `string` | - | Additional CSS classes |

## Features

- **Multi-format** : Support for URLs, Blobs, Base64 and static imports
- **Interactive controls** : Like, dislike, copy prompt, download
- **Loading states** : Loading indicator during download
- **Automatic download** : Management of different formats for download
- **Prompt copy** : Easy copy of used prompt
- **Responsive** : Adapts to all screen sizes
- **Accessibility** : Screen reader support
