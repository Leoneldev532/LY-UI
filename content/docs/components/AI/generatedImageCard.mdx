# Generated Image Card

Un composant de carte d'image générée par IA avec options de téléchargement, partage et gestion des métadonnées.

## Utilisation

```tsx
import { GeneratedImageCard } from '@/components/LY UI/AI/generatedImageCard'

export default function ImageExample() {
  return (
    <GeneratedImageCard
      imageUrl="https://example.com/generated-image.jpg"
      prompt="Un chat dans un jardin fleuri"
      onDownload={(url) => {
        console.log('Téléchargement:', url)
      }}
    />
  )
}
```

## Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `imageUrl` | `string` | - | URL de l'image générée |
| `prompt` | `string` | `""` | Prompt utilisé pour générer l'image |
| `onDownload` | `(url: string) => void` | - | Callback lors du téléchargement |
| `className` | `string` | - | Classes CSS supplémentaires |
| `showPrompt` | `boolean` | `true` | Affiche le prompt utilisé |
| `showDownloadButton` | `boolean` | `true` | Affiche le bouton de téléchargement |
| `showShareButton` | `boolean` | `true` | Affiche le bouton de partage |
| `metadata` | `ImageMetadata` | - | Métadonnées de l'image |

## Types

```tsx
interface ImageMetadata {
  model?: string
  size?: string
  quality?: string
  timestamp?: string
  seed?: number
}
```

## Fonctionnalités

- **Affichage d'image** : Rendu optimisé avec lazy loading
- **Téléchargement** : Bouton de téléchargement direct
- **Partage** : Options de partage sur les réseaux sociaux
- **Métadonnées** : Affichage des informations de génération
- **Responsive** : S'adapte à toutes les tailles d'écran

## Exemples

### Image simple

```tsx
<GeneratedImageCard
  imageUrl="https://api.example.com/images/cat-garden.jpg"
  prompt="Un chat orange dans un jardin avec des fleurs"
/>
```

### Avec métadonnées

```tsx
<GeneratedImageCard
  imageUrl="https://api.example.com/images/landscape.jpg"
  prompt="Paysage de montagne au coucher du soleil"
  metadata={{
    model: "DALL-E 3",
    size: "1024x1024",
    quality: "high",
    timestamp: "2024-01-15T10:30:00Z"
  }}
  onDownload={(url) => {
    // Logique de téléchargement personnalisée
    downloadImage(url, "paysage-montagne.jpg")
  }}
/>
```

### Sans boutons

```tsx
<GeneratedImageCard
  imageUrl="https://api.example.com/images/abstract.jpg"
  prompt="Formes abstraites colorées"
  showDownloadButton={false}
  showShareButton={false}
  className="max-w-sm"
/>
```

### Avec gestion d'erreur

```tsx
<GeneratedImageCard
  imageUrl="https://api.example.com/images/portrait.jpg"
  prompt="Portrait d'une femme dans un style renaissance"
  onDownload={(url) => {
    try {
      downloadImage(url)
      toast.success('Image téléchargée !')
    } catch (error) {
      toast.error('Erreur lors du téléchargement')
    }
  }}
/>
```
