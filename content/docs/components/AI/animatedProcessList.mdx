# Animated Process List

An animated process list component that displays steps with progressive revelations, scroll animations, and skeleton loading states.

## Example

```tsx
import { AnimatedProcessList } from '@/components/LY UI/AI/animatedProcessList'

export default function ProcessExample() {
  const processSteps = [
    "Initializing system...",
    "Loading dependencies...",
    "Processing data...",
    "Generating response...",
    "Finalizing output..."
  ]

  const handleAnimationEnd = () => {
    console.log('Animation ended')
  }

  return (
    <AnimatedProcessList
      title="Processing your request"
      processSteps={processSteps}
      animationSpeed="normal"
      scrollDirection="up"
      onAnimationEnd={handleAnimationEnd}
      skeletonDuration={2000}
      lineRevealDelay={150}
      className="w-full max-w-lg"
    />
  )
}
```

## Documentation

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `title` | `string` | `"Generating elements for your web page"` | Title displayed at the top of the component |
| `processSteps` | `string[]` | `[]` | Array of process steps to display |
| `className` | `string` | - | Additional CSS classes |
| `scrollDirection` | `"up" \| "down"` | `"up"` | Direction of scroll animation |
| `animationSpeed` | `"slow" \| "normal" \| "fast"` | `"normal"` | Animation speed |
| `onAnimationEnd` | `() => void` | - | Callback called when revelation animation ends |
| `skeletonDuration` | `number` | `2000` | Duration in milliseconds of skeleton phase |
| `lineRevealDelay` | `number` | `150` | Delay in milliseconds between each line revelation |

## Features

- **Scroll animation** : Continuous scrolling of elements with configurable direction
- **Progressive revelations** : Sequential appearance of steps with configurable delay
- **Skeleton state** : Loading phase with pulse animation
- **Animation speeds** : Three speed levels (slow, normal, fast)
- **Callbacks** : Notifications for animation events
- **Responsive** : Adapts to all screen sizes
- **Accessibility** : Screen reader support
