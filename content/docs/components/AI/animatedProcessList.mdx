# Animated Process List

Un composant de liste de processus avec des animations séquentielles et des indicateurs de progression visuels.

## Utilisation

```tsx
import { AnimatedProcessList } from '@/components/LY UI/AI/animatedProcessList'

const processes = [
  { id: 1, title: "Analyse des données", status: "completed" },
  { id: 2, title: "Traitement IA", status: "active" },
  { id: 3, title: "Génération de réponse", status: "pending" }
]

export default function ProcessExample() {
  return (
    <AnimatedProcessList
      processes={processes}
      isActive={true}
      className="space-y-4"
    />
  )
}
```

## Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `processes` | `ProcessItem[]` | `[]` | Liste des processus à afficher |
| `isActive` | `boolean` | `false` | Active les animations |
| `className` | `string` | - | Classes CSS supplémentaires |
| `animationSpeed` | `number` | `1000` | Vitesse des animations en ms |
| `showProgress` | `boolean` | `true` | Affiche les barres de progression |

## Types

```tsx
interface ProcessItem {
  id: number | string
  title: string
  status: 'pending' | 'active' | 'completed' | 'error'
  description?: string
  progress?: number // 0-100
}
```

## États des processus

- **pending** : En attente, animation de pulsation
- **active** : En cours, animation active
- **completed** : Terminé, indicateur de succès
- **error** : Erreur, indicateur d'erreur

## Exemples

### Liste avec progression

```tsx
const processes = [
  { id: 1, title: "Initialisation", status: "completed", progress: 100 },
  { id: 2, title: "Analyse", status: "active", progress: 65 },
  { id: 3, title: "Finalisation", status: "pending", progress: 0 }
]

<AnimatedProcessList
  processes={processes}
  isActive={true}
  animationSpeed={800}
/>
```

### Liste simple

```tsx
<AnimatedProcessList
  processes={[
    { id: 1, title: "Étape 1", status: "completed" },
    { id: 2, title: "Étape 2", status: "active" },
    { id: 3, title: "Étape 3", status: "pending" }
  ]}
  isActive={true}
  showProgress={false}
/>
```
