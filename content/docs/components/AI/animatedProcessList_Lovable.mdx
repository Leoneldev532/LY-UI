## Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `lines` | `LineItem[]` | `[]` | Array of line items with icons and content |
| `className` | `string` | `undefined` | Additional CSS classes for styling |
| `animationSpeed` | `"slow" \| "normal" \| "fast"` | `"normal"` | Speed of the animation |
| `scrollDirection` | `"up" \| "down"` | `"up"` | Direction of the scrolling animation |

### LineItem

| Prop | Type | Description |
|------|------|-------------|
| `icon` | `ReactNode` | Icon component to display |
| `content` | `string` | Text content for the line |

### Example Usage

```jsx
import AnimatedProcessList_Lovable from "@/components/LY UI/AI/animatedProcessList_Lovable";
import { CheckCircle, Settings } from "lucide-react";

<AnimatedProcessList_Lovable
  lines={[
    {
      icon: <CheckCircle className="w-5 h-5 text-green-600" />,
      content: "Processing your request...",
    },
    {
      icon: <Settings className="w-5 h-5 text-blue-600" />,
      content: "Configuring the response...",
    },
  ]}
  animationSpeed="normal"
  scrollDirection="up"
  className="h-64"
/>
```
